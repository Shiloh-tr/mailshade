## Validator audit finding

The strict tooling audit found and fixed two proof-integrity issues: the validator previously fell back to a generic inversion prior when a fitted candidate had no anchors, and the standalone calibration interpolation used absolute saturation where the runtime used source-relative saturation. The CLI now selects the fitted role model correctly, refuses to call fitting data a release gate without an explicit diagnostic override, and has a parity test that requires CLI and runtime interpolation to return identical colors.

## Retired candidate: typography auto-sizing

An initial crop from the earlier naturally dark holdout appeared to show reflow and scored SSIM `0.762035`. The later 12-probe paired light/dark run demonstrated that this was a capture-method artifact: the comparison mixed viewport widths, font rasterizers, and scaling. Gmail dark mode did not change the measured wrapping, and this candidate is retired.

This remains a candidate until the dedicated `text-autosizing-matrix` confirms which declarations and layout conditions activate or suppress the behavior. The existing profile has not been changed.
